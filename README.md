# Job Portal

A comprehensive web-based job portal application built with Java, HTML, CSS, JavaScript, and SCSS. This project provides a platform for job seekers to find employment opportunities and employers to post job listings.

## 📖 About

Jobportal is a full-stack job recruitment platform that connects job seekers with employers. It provides a seamless experience for users to search, apply, and manage job opportunities, while enabling employers to post listings and review applications efficiently.

## 📋 Project Overview

Job Portal is a full-stack application designed to connect job seekers with employers. The platform facilitates job searches, applications, and employer recruitment management in a user-friendly interface.

## 🚀 Getting Started

### Prerequisites
- Java Development Kit (JDK) 8 or higher
- A modern web browser (Chrome, Firefox, Safari, Edge)
- Maven or Gradle (if using build tools)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Harijogi333/Jobportal.git
   cd Jobportal
   ```

2. **Set up the project**
   - Navigate to the `jobportal` directory
   - Configure your build tool (Maven/Gradle)
   - Install dependencies

3. **Build the project**
   ```bash
   # Using Maven
   mvn clean install
   
   # Using Gradle
   gradle build
   ```

4. **Run the application**
   ```bash
   # Start the server and access the application in your browser
   ```

## ✨ Features

- **Job Search**: Browse and search for job listings with various filters
- **Job Application**: Apply to job postings easily
- **Employer Dashboard**: Post and manage job listings
- **User Profiles**: Create and manage job seeker and employer profiles
- **Responsive Design**: User-friendly interface that works on all devices
- **Secure Access**: User authentication and authorization

## 📖 Usage

1. **For Job Seekers**
   - Create an account
   - Search for jobs using various filters
   - Apply to interesting positions
   - Track your applications

2. **For Employers**
   - Register as an employer
   - Post new job listings
   - Manage and track applications
   - Communicate with applicants
